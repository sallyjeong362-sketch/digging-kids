# 두더지 퀴즈 (Mole Quiz) 🦡

**두더지 퀴즈**는 초등 저학년 아이도 혼자서 바로 즐길 수 있는, 쉽고 재미있는 관심사 퀴즈 게임입니다.
[Digging](https://github.com/sallyjeong362-sketch/digging)의 "꼬리에 꼬리를 무는 탐구" 정신을 더 쉽고 게임처럼 풀어낸 자매 프로젝트예요.

## 어떻게 동작하나요?

넓고 얕은 트리비아 대신, **하나의 구체적인 대상을 3단계로 점점 깊게 파고드는** 방식이에요.

1. **관심사 고르기** — 동물, 공룡, 우주, 바다, 음식, 탈것, 미술·색깔, 날씨·자연 중 하나를 콕 눌러요.
2. **파고들 대상 고르기** — 예를 들어 "동물"을 고르면 "기린"과 "펭귄" 중 하나를 골라요.
3. **점점 깊어지는 3문제** — 기본적인 사실 → 더 구체적인 디테일 → "왜?"를 묻는 질문까지, 깊이가 "N층"으로 계속 쌓여요.
4. **더 파고들지 선택** — 한 대상을 다 파면 연관된 다음 대상(다른 주제일 수도 있어요)으로 계속 이어갈지, 여기서 그만할지 골라요. 여러 대상을 이어서 팔수록 깊이 기록이 쌓여요.
5. **뱃지 모으기** — 한 관심사 안의 대상을 하나라도 다 파면 그 관심사 뱃지를 획득해요. 모은 별·뱃지·최고 깊이 기록은 "내 뱃지 모음"에서 확인해요.

[Digging](https://github.com/sallyjeong362-sketch/digging)의 "하나의 질문에서 시작해 꼬리에 꼬리를 물고 더 깊이 파고든다"는 핵심은 그대로 가져오고, 글 읽기·로그인 부담 없이 누르고 바로 배우는 퀴즈 형식으로만 쉽게 풀었습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
```

React + TypeScript + Vite + Tailwind CSS + Zustand(localStorage에 진행 상황 저장). 백엔드 없이 전부 브라우저에서 동작합니다.

`main` 브랜치에 푸시하면 GitHub Pages로 자동 배포됩니다.
