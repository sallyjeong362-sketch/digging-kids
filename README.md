# 두더지 퀴즈 (Mole Quiz) 🦡

**두더지 퀴즈**는 초등 저학년 아이도 혼자서 바로 즐길 수 있는, 쉽고 재미있는 관심사 퀴즈 게임입니다.
[Digging](https://github.com/sallyjeong362-sketch/digging)의 "꼬리에 꼬리를 무는 탐구" 정신을 더 쉽고 게임처럼 풀어낸 자매 프로젝트예요.

## 어떻게 동작하나요?

1. **주제 고르기** — 동물, 공룡, 우주, 바다, 음식, 탈것, 미술·색깔, 날씨·자연 중 하나를 콕 눌러요.
2. **퀴즈 풀기** — 큰 그림과 짧은 질문을 보고 O/X 또는 그림 선택지 중 하나를 골라요.
3. **바로 피드백** — 정답이면 별을 받고, 틀려도 괜찮아요! 두더지 친구가 짧은 사실을 알려줘요.
4. **뱃지 모으기** — 한 주제를 다 풀면 뱃지를 획득해요. 모은 별과 뱃지는 "내 뱃지 모음"에서 확인할 수 있어요.

글을 길게 읽거나 로그인할 필요 없이, 누르고 바로 배우는 데 집중했습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
```

React + TypeScript + Vite + Tailwind CSS + Zustand(localStorage에 진행 상황 저장). 백엔드 없이 전부 브라우저에서 동작합니다.

`main` 브랜치에 푸시하면 GitHub Pages로 자동 배포됩니다.
